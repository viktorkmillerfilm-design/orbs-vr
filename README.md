# orbs vr

prototype: the orbs solar system in 3d / webxr. grab planets and move them: distance sets the lap, height sets the octave. works with mouse, touch, and in vr/ar headsets (enter vr).

open: https://viktorkmillerfilm-design.github.io/orbs-vr/

three.js (MIT) and iwer (MIT) are vendored in lib/.
